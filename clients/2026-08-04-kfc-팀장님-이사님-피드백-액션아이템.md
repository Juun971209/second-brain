# KFC 앱 팀장님·이사님 피드백 액션아이템 (07.30 + 08.04)

## 핵심 요약
07.30 팀 리뷰 + 08.04 상세 리뷰 + Figma 인라인 코멘트를 중복 제거해 8개 액션 아이템(4-1~4-8)으로 재구성. 종합 진단은 "현재 덱이 데이터를 나열하는 단계에 머물러 있고, 데이터가 무엇을 증명하는지로 넘어가지 못하고 있다"는 것. 각 항목은 [문제] → [원인] → [액션] 구조로 정리되어 있고, 액션 아이템 DB의 4-1~4-8과 1:1로 연결됨.

## 상세 내용

### 종합 진단
현재 덱은 "데이터를 나열"하는 단계에 머물러 있고, "데이터가 무엇을 증명하는지"로 넘어가지 못하고 있다. 07.30과 08.04 피드백 모두 같은 문제를 다른 각도에서 지적.

### 1. 현황분석 결론이 없다
- **문제:** 현황분석 파트를 마무리하는 결론 슬라이드가 없어서 배경·VOC·UI리뷰·플로우가 각자 따로 놀고 어디로 수렴하는지 안 보임.
- **원인:** 슬라이드를 데이터 소스 단위(현황데이터/VOC/UI리뷰/플로우)로만 구성하고, 종합하는 마지막 한 장이 없었음.
- **액션(4-1):** "성장은 하지만 격차는 여전하다" 톤의 결론 슬라이드 신규 제작. 예시 헤드라인: "KFC앱은 멤버십과 앱 주문이 성장하고 있지만, 설치 고객의 실사용 전환과 경쟁 앱 대비 이용 규모에는 여전히 격차가 있다"

### 2. 현황분석 범위가 KFC 앱 안쪽에 갇혀 있다
- **문제:** "왜 이 앱을 개선해야 하는가"에 대한 바깥쪽 맥락(시장·생태계·고객)이 없어 근거가 약하게 느껴짐.
- **원인:** 현황분석이 KFC 앱 내부 지표(MAU·이탈률·업데이트 이력)에만 집중.
- **액션(4-2):** "KFC 앱 개요" 슬라이드 신규 추가 — ① 앱의 역할과 목적 ② 주문 서비스 생태계 내 포지션(배달앱·경쟁사 대비) ③ 주요 고객 유형 3종(헤비/라이트/미사용).

### 3. VOC 슬라이드가 건수 집계에서 멈춘다
- **문제:** "리뷰는 딜리버리·쿠폰·사용성에 가장 많이 모였다"는 헤드라인이 건수만 보여줄 뿐 왜 문제인지 설명 안 함.
- **원인:** 카테고리별 건수 표는 있지만 상황→불편→결과로 이어지는 인과 서술이 빠짐.
- **액션(4-3):** 대표 사례 2개를 "상황 → 불편 → 결과" 3단 카드로 추가.

### 4. UI 인벤토리가 분류만 하고 발견이 없다
- **문제:** 전 화면을 Foundation·Components로 분류했지만 "그래서 뭘 발견했는지"가 안 보임.
- **원인:** 인벤토리 슬라이드가 분류 체계만 보여주고 영역별 해석이 없음.
- **액션(4-4):** 홈·메뉴·장바구니·쿠폰·결제 5개 영역별 한 줄 인사이트 슬라이드 신규 추가. 예시: "장바구니 — 메인에서 바로 접근, 진입성은 양호. 이후 쿠폰 적용과 결제 흐름이 복잡해 빠른 주문 완료로 연결되지 않음"

### 5. 플로우차트를 읽을 수가 없다
- **문제:** 프로세스 확인이 어렵고 무엇을 보여주려는 건지 이해가 안 됨.
- **원인:** 로우데이터 수준의 전체 플로우를 그대로 넣어 핵심 분기점·단절구간이 다른 정보에 묻힘.
- **액션(4-5):** 분기점 3곳·쿠폰-주문 단절구간 1곳만 색상·아이콘으로 강조해 재작업.

### 6. 페인포인트 4개의 근거가 불명확하다
- **문제:** 페인포인트로 제시된 항목들이 왜 문제인지 근거·이유 설명 부족.
- **원인:** "무엇이 문제다"라고만 말하고 왜 그렇게 판단했는지 논리가 생략됨.
- **액션(4-8):** 불명확한 4개 페인포인트 각각에 근거·이유 1줄씩 보강.
- **병행(은지·지현):** 타사(버거킹·맥도날드·롯데리아 등) 레퍼런스 벤치마킹 분석 — 아직 누락 상태.

### 7. 인라인 디테일 3건
- **04p · About KFC** (김봉주 본부장님): "리뉴얼된 로고인가요? 현재 사용 중인 이전 로고가 함께 보여야 할 것 같습니다." → 26년 리뉴얼 로고만 단독 표기 중, 구로고 병기 필요.
- **08p · 앱 노후화 인지 슬라이드**: "데이터 출처 기재 필요. 동일한 위계의 줄글로 배치되어 있어 한눈에 안 들어옴." → 불릿별 출처(앱스토어·공식발표·모바일인덱스 등) 명시 + 위계 분리 필요.
- **09p · VOC 라이더 요청사항**: "하이라이트만으로는 장표에서 안 보여서, 확대+플로팅 등 효과로 파악하기 쉽게." → 핵심 인용구를 확대 콜아웃으로 별도 강조 필요.
- **액션(4-6):** 위 3건 일괄 수정.

### 8. 전체 톤 — 구어체, 척추 없음
- **문제:** 구어체 표현이 섞여 있고 프로젝트 전체를 관통하는 기준점이 안 보임.
- **원인:** 슬라이드별 개별 작성으로 전체를 관통하는 문어체·구조 기준이 불통일.
- **액션(4-7):** 전체 덱 구어체 표현 검색 후 문어체로 일괄 수정. (참고: 5번 결론 슬라이드가 먼저 만들어지면 그 결론을 기준으로 나머지 슬라이드 위계도 자연스럽게 맞춰짐)
